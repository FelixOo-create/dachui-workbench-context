# 标签书签工作台迭代交接

## 目标与结果

书签页从侧栏管理界面调整为标签驱动的个人书签工作台。保留原数据和核心功能，不引入待办、日历、倒计时、自由组件或星团视图。

已落地：

- 顶部标签视图、紧凑/预览卡片墙和近黑哑光视觉。
- 浏览器地址栏、网页链接和 URL 文本拖入收藏。
- 重复 URL 在当前标签下的兼容处理。
- Chrome、Edge、QQ 浏览器 Profile 配置与卡片多入口。
- 回环监听、Origin 限制、受控浏览器进程参数和每日数据备份。
- Chrome 新标签页与工作台内嵌共用同一页面。

## 关键决策

- 浏览器会话由浏览器 Profile 保持，本工具不读取或保存 Cookie、密码。
- 浏览器入口是全局配置；书签只保存引用和可选按钮名称。
- 旧收藏缺失 launchTargets 时按空数组读取，无强制迁移。
- 真实 data/ 不参与测试，集成测试使用临时目录。

## 入口与验证

- 服务：server.js
- 页面：public/index.html、public/app.js、public/styles.css
- 测试：tests/server.test.mjs
- 验证：npm run check、npm test

## 后续入口

- 若需要支持 Firefox，应单独设计其 Profile 参数，不复用 Chromium 参数。
- 若账号入口数量显著增加，可为 Profile 增加分组和排序；当前不增加管理层级。
