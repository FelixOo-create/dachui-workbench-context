# 大锤的工作台：GPT 项目背景

## 1. 产品目标

这是一个个人 Windows 本地工作台，用统一窗口承载日常管理、专注统计和工具入口。核心目标是减少在多个独立工具、窗口和文件夹之间来回切换，同时保持各个外部工具的独立运行边界。

当前方向是“模拟桌面的 Electron 壳层”，不是绑定 Explorer，也不是将所有子工具源码强行合并到一个进程。

## 2. 全局框架

- 顶部：天气/日期等轻量环境信息、七个内部场景导航、版本与少量全局状态。
- 中部：当前完整场景或首页组件网格。
- 底部 Dock：全部工具、固定工具与文件夹、布局、设置和时钟。
- 固定场景：今日、待办、今日专注/时间统计、习惯、纪念册、画布、工具。

完整业务页面直接在主内容区渲染，不再使用“打开页面”式入口卡片。

## 3. 首页规划

首页是“今日摘要与快捷操作中心”，不是把所有完整功能压缩在一起。

默认核心组件：

1. **常用入口 / 桌面盒子**：主卡片。展示收藏工具、应用快捷方式、项目和文件夹入口，只镜像入口，不整理真实文件。
2. **今日待办**：展示今天需要关注的任务，支持快速添加和完成，复杂编辑进入完整待办页。
3. **日历摘要**：当前日期、少量日程和进入完整日历的入口。
4. **专注计时**：开始、暂停或继续番茄钟，复杂标签统计与时间总结进入今日专注页。

可选组件：天气、回收站、电源等。天气不是默认核心组件；“历史上的今天”仍为延后能力；旧预览中的“接下来”只是版面概念，不是已确认的独立业务组件。

首页支持组件增删/显隐、排序、尺寸调整、显示器级布局保存，以及智能填充、二分、三分、四宫格、主次和自由布局预设，并保留一次撤销。

## 4. 已迭代功能页

### 待办 V2

- 清单和智能视图；
- 任务创建、编辑、删除和完成状态；
- 日期、时间、提醒、优先级和子任务；
- 排序与右侧日历联动；
- 首页仅显示摘要，完整能力留在待办页。

### 今日专注

- 番茄钟开始、暂停、继续、重置和完成记录；
- 沿用原时间块活动/分类标签；
- 完成的番茄自动进入一日时间流；
- 按标签汇总投入时间，并提供当日专注摘要；
- 以真实记录计算，不使用虚构效率评分或 AI 建议。

### 习惯 V2

- 今日打卡、创建和编辑习惯；
- 完成率、连续天数与趋势；
- 已接入现有 Store/API。

### 纪念册 V2

- 书籍、电影和剧集记录；
- 列表、筛选、时间线、新建和编辑；
- 支持封面粘贴与现有业务数据接口。

### 工具中心

- 工具搜索、分类与运行状态；
- 启动、停止、扫描、添加、编辑和移除注册；
- 移除注册不删除源项目。

## 5. 视觉语言

- 近黑、低饱和炭灰；
- 克制的雾面玻璃质感；
- 细边框、统一圆角和柔和阴影；
- 薄荷绿表示完成、运行和积极状态；
- 暖金表示提醒、准备或重点；
- 中文必须清楚可读，避免过小字体；
- 标题、说明、数据和操作形成清楚层级；
- 页面边距、标题三行节奏和主内容卡片材质需要跨页面统一。

习惯页与纪念册页是当前页面外壳、标题位置和整体边距的重要参考。GPT 概念图主要决定布局、层级、空间利用和设计感，不是像素级实现合同。

## 6. GPT 设计边界

必须保留：

- 当前真实业务功能和数据来源；
- 顶部场景导航与底部 Dock；
- 项目现有近黑低饱和视觉体系；
- 真实页面之间的一致性。

可以调整：

- 卡片占比、排列和视觉层级；
- 字号、间距、对齐和内容密度；
- 合理的色块、边框、阴影和状态表达；
- 在真实组件和响应式限制下进行适配。

不要引入：

- 没有真实数据来源的统计；
- AI 自动总结、效率评分和虚构建议；
- 不存在的协作、社交或云端能力；
- 会移动、删除或重命名用户文件的桌面管理；
- 过度3D、粒子、强发光或无法合理落地的折射效果；
- 预览图中看似合理、但项目没有实际用途的控件。

## 7. 预览与实施协作

1. 用户和 Sol 确认功能与产品方向。
2. GPT 根据当前截图和背景生成一张主要预览；必要时再补一个关键交互态。
3. Sol 将批准方向收敛为“必须匹配、可以调整、不得照搬”。
4. 用户把预览图和精简交接提示词交给 Luna。
5. Luna完成真实代码、测试和运行截图。
6. Sol 分别检查功能正确性和视觉还原度，集中验收。

GPT 生成的图片不是功能证明，最终以真实运行截图和业务验证为准。
