# 纪念册 V2 实施基线

## 基线文件

- `approved-default.png`：封面墙主状态，1920×1080。
- `approved-create.png`：新建纪念弹窗，1920×1080。
- `approved-timeline.png`：时间长廊状态，1920×1080。

这三张图片是本轮纪念册真实落地的视觉基线。新版可以替换旧版页面结构和样式；遇到旧布局与基线冲突时，以基线为准，不再为了复用旧组件降低还原度。

## 固定视觉决策

- 使用近黑、低饱和的炭灰体系，搭配少量薄荷绿和暖金状态色；不得回到蓝紫主色。
- 页面保持统一工作台顶部场景导航和底部工具栏，纪念册内容区采用左侧分类、中间内容、右侧详情/统计的清晰层级。
- 页面级骨架、标题区和外边距以 `references/habit-page-shell-standard.png` 的习惯页为统一标准：标题左边线、内容最大宽度、顶部留白、左右边距和底部工具栏间距需对齐。纪念册当前问题见 `references/memory-page-shell-current-issue.png`。
- 板块最外层不再增加覆盖整个页面的大边框/大圆角容器；页面直接落在工作台背景上，只给真正承载信息的内部卡片、侧栏和内容面板设置边框。
- 卡片使用轻透明、细边框、局部柔光和克制阴影；不使用大片实心灰块，也不依赖不可落地的图片生成特效。
- 封面墙以 3×2 主卡片矩阵和右侧选中详情为基准；卡片尺寸、留白、文字层级和选中边框应接近 `approved-default.png`。
- 新建/编辑使用居中毛玻璃弹窗，左侧封面操作、右侧表单、底部固定操作区，结构以 `approved-create.png` 为准。
- 时间长廊以横向悬浮卡片作为节点：中心卡放大并提亮，邻近卡逐级缩小和压暗；卡片与底部时间刻度线相互独立，右侧保留年度记忆地图和年度节奏信息，结构以 `approved-timeline.png` 为准。

## 必须保留的真实业务能力

- 从现有本地纪念册服务读取和保存真实记录，不读取或改写用户数据库内容做开发验证，不创建第二套数据源。
- 保留书籍、电影、剧集分类，以及标题、作者/主创、发行年份、季度、完成日期、评分、短评、完整评语、标签和重读/重看状态。
- 保留搜索、分类筛选、封面墙/时间线切换、详情查看、新建、编辑、删除和界面偏好持久化。
- 保留封面粘贴、本地图片选择、移除封面和无封面保存；继续封存在线封面 API，不恢复 TMDB 或其他申请 Token 的路径。
- 年度记忆地图、月份节奏、分类数量、关键词和时间轴节点必须由当前记录计算，不得硬编码预览数字。
- 加载、空数据、搜索无结果、保存失败和图片失败状态必须可用，并延续统一视觉。

## 关键交互规则

1. 封面卡或时间轴卡被选中时，同步更新右侧详情；新建、编辑、删除完成后列表、统计、当前选中项立即一致更新。
2. 时间长廊支持点击卡片、左右按钮、键盘方向键和横向拖动切换节点；当前项始终回到视觉中心，底部刻度同步定位，但刻度线不与卡片拼接。

## 可调整范围

- 为适配真实窗口尺寸和性能，可微调卡片间距、模糊半径、阴影强度及 180–260ms 范围内的动画时长。
- 允许在窄屏降低同屏可见节点数，但 1920×1080 主状态需接近基线的密度、比例和层级。
- 预览中的渐变封面只是无真实封面时的视觉占位；真实本地封面必须正常显示。

## 验收门槛

- 功能：运行 `npm run typecheck`、`npm run test`；若修改主进程、IPC 或本地服务，再运行 `npm run package`。
- 视觉：使用隔离测试数据在 1920×1080 分别截取封面墙、新建弹窗、时间长廊，与三张基线逐项对照布局、密度、材质、层级和状态。
- 页面一致性：额外与习惯页对照页面标题位置、内容起始线、左右边距、底部间距和外层边缘；不得保留纪念册整页大框。
- 交付报告需分别说明“功能通过情况”和“视觉还原情况”；任何不能一致的地方必须给出真实技术限制，不得用旧组件复用作为默认理由。
