## 产品定位

这是一个 Windows 本地 Electron 工作台，在统一壳层中直接呈现今日、待办、今日专注、习惯、纪念册、画布和工具中心，并通过统一入口启动独立工具。

它不是 Explorer 桌面替代品，不移动、删除或重命名用户的真实桌面文件。业务数据保留在 Electron `userData`，不会进入本仓库。
